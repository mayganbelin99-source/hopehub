🌸 HopeHub: Your Cancer Companion App

Quick Start
	1.	Open the HopeHub app link
	2.	Sign in with Google
	3.	Your profile is created automatically
	4.	Start tracking your health, moods, and support journey

⸻

HopeHub is a comprehensive cancer companion application that supports patients and caregivers throughout the cancer journey. It combines centralized health management, AI-powered personalization, caregiver integration, and emotional support — all in one platform.

⸻

🚀 How New Users Join
	1.	Visit the App → Go to the deployed HopeHub link
	2.	Sign In → Tap “Continue with Google”
	3.	Auto-Profile Creation → A personal profile is created automatically on first sign-in
	4.	Personalized Experience → Each user gets their own private, secure space

⸻

👤 What Each User Gets
	•	✅ Personal Profile: Name, email, mantra, diagnosis date, favorite colors
	•	✅ Private Health Data: Medications, symptoms, appointments
	•	✅ Individual Tracking: Mood entries, nutrition logs, scan history
	•	✅ Custom AI Suggestions: Personalized meals & calming activities
	•	✅ Barcode Scanner: Nutrition analysis & history
	•	✅ Caregiver Management: Invite trusted caregivers for support

⸻

🔒 Data Privacy & Security
	•	Completely Separate → Each user only sees their own data
	•	Secure Authentication → Google OAuth login
	•	HIPAA-Style Privacy → Health data is isolated per user
	•	No Cross-Access → Users cannot view each other’s information

⸻

🌟 Key Features
	•	Centralized Health Management → No scattered tools, everything in one place
	•	AI-Powered Personalization → Smart suggestions for meals and activities
	•	Caregiver Integration → Share access with family or friends
	•	Evidence-Based Recommendations → Nutrition analysis & health scoring
	•	Emotional Support → Crisis resources & calming activities

⸻

💡 Why HopeHub Matters

Managing cancer is overwhelming. HopeHub simplifies care by putting health tracking, emotional support, and personalized tools into one easy app. It empowers patients and helps caregivers provide better support.

✨ Because no one should face cancer alone.
