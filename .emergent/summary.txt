<product_requirements>
The user, a breast cancer survivor, envisions HopeHub as a comprehensive, one-stop application to ease the cancer journey. The core problem is the isolation and overwhelming nature of managing treatment, symptoms, mental health, and resources without adequate support.

**Initial Core Features:**
1.  **Cancer Companion:** Track meds, side effects, appointments; symptom log with graphs; daily gentle reminders.
2.  **Nutrition Helper:** Food barcode scanner for health score/alternatives; quick, fatigue-friendly recipes; meal suggestions based on conditions (diabetes, low immunity, nausea-friendly).
3.  **Mental Health Buddy:** Daily mood check-in (emoji/slider); journaling prompts; calming tools (breathing timer, grounding, affirmations); crisis resources.
4.  **Local Resource Finder:** Directory of nearby food pantries, clinics, support groups, transport; map view/directions; community suggestion option.

**Key Integrations:** Firebase (for user data), Google Maps API, AI (meal/calming suggestions).
**Design:** Clean, calming, supportive (soft colors, intuitive buttons).

**Evolving Requirements (User-driven):**
*   **Authentication & Privacy:** Users create accounts and sign in for personalization and data security (prompted by user's personal journey).
*   **Caregiver Shared Access:** Patient-controlled full access for designated caregivers.
*   **Patient Profile Page:** Personalization with photo upload, mantras, treatment milestones, fighting for section, diagnosis date, favorite colors/themes.
*   **AI Integration:** Specifically, OpenAI GPT-5 for meal suggestions and calming activity recommendations, using Emergent LLM key.
*   **Implementation Order:** All external integrations need to be complete in the order the user listed (AI, then Google Maps, then Barcode Scanner).
</product_requirements>

<key_technical_concepts>
-   **Full-stack Architecture:** React frontend, FastAPI backend, MongoDB database.
-   **FastAPI:** Python web framework for backend APIs.
-   **MongoDB:** NoSQL database for flexible data storage (using UUIDs, not ObjectIDs).
-   **React:** JavaScript library for building user interfaces (utilizing Shadcn UI components).
-   **Tailwind CSS:** Utility-first CSS framework for styling.
-   **Emergent Authentication:** Custom library for Google Social Login and secure session management.
-   **Emergent LLM Key:** Universal key for OpenAI (GPT-5) and other LLM integrations.
-   **Open Food Facts API:** Third-party API for barcode scanning and nutrition data.
-   **Kubernetes Ingress:** Handles '/api' prefix routing for backend, other routes for frontend.
</key_technical_concepts>
